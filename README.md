# 星夜マート — 雨の街角

用 three.js 纯代码搭出来的**雨夜便利店街角微缩模型**。没有任何外部模型或图片资源——所有贴图都由 Canvas 2D 现场绘制，所有几何体都由代码生成。

卡通渲染 + 泛光后期，配上持续落下的雨、地面的涟漪和自动开合的玻璃门。

## 特性

- **卡通渲染** — `MeshToonMaterial` 配渐变贴图做色阶，叠加 `UnrealBloomPass` 泛光
- **便利店本体** — 玻璃幕墙、会定时自动开合的门、招牌与雨棚、室内冷柜、货架、收银台（关东煮、杂志、海报、吊灯）
- **街道道具** — 自动售货机、自行车、雨伞架／垃圾桶／告示板、路灯、电线杆与电线、护栏、停车标志、信号灯、公寓楼、远景楼群
- **天气系统** — 带风偏的雨丝粒子，落到屋顶和雨棚上会停在地面高度而不是穿模；湿地面涟漪、水洼、棚檐滴水
- **全程序化贴图** — 沥青、人行道、盲道、卷帘门、招牌、便利店海报……全部用 Canvas 现画，零图片资源
- **交互** — 拖拽旋转、滚轮缩放（已禁用平移并限定俯仰角），载入时有推镜动画
- **响应式** — 触屏 / 窄屏自动放宽视野、降低分辨率上限与阴影贴图尺寸

## 快速开始

需要 [Node.js](https://nodejs.org/)（装 `three` 依赖）和 Python 3（只用来起一个静态服务器）。

```bash
npm install
```

**Windows**：双击 `start.bat`，它会自动起服务器并打开浏览器。

**其他平台**：

```bash
npx serve .            # 或者
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

> ⚠️ 必须通过 HTTP 服务器打开。直接双击 `index.html` 会因 import map / ES Module 的跨域限制而白屏。

## 项目结构

```
index.html        页面骨架、import map、载入遮罩
start.bat         Windows 一键启动脚本
src/
  main.js         渲染器、相机、灯光、后期处理、主循环
  core.js         调色板、卡通材质、Canvas 贴图工具
  layout.js       场景坐标系与布局常量
  base.js         地面、道路、人行道、水洼
  store.js        便利店建筑、玻璃幕墙、自动门、店内陈设
  props.js        街道道具与周边建筑
  weather.js      雨、涟漪、水洼反光、檐口滴水
  textures.js     全部程序化贴图
```

## 技术要点

- `importmap` 直接指向 `node_modules/three`，不走打包流程——改完代码刷新页面即可，没有构建步骤
- 所有需要逐帧更新的对象都注册进 `world.updatables`，主循环统一驱动
- 布局参数集中在 `layout.js`，随时可以整体挪动或缩放场景
